Transfer Custody

chain of custody

Only the current custodian may hand an item off — the chaincode itself enforces this. Signed in as someone else, the transaction is rejected on-chain, not just in this UI.

Required — NIST SP 800-86 / ISO 27037 / SWGDE all treat the reason for a custody handoff as part of the record, not just who and when. Recorded on-chain, permanently.
